# Catalyst Documentation Shortcuts - Development Instructions

## Project Overview
A Chrome extension that displays quick links to documentation websites. Click the extension icon to see a popup with hardcoded documentation links. Each link has "Open Documentation" and "Copy Link" buttons for easy access.

## Quick Build & Test
```bash
npm run build:extension  # Build the extension to dist-extension/
```
Then load `dist-extension/` folder in `chrome://extensions/` (Developer mode).

## Features
- **Quick Links Display**: Shows hardcoded documentation links in a clean card layout
- **Open Documentation**: Click button to open link in new Chrome tab via `chrome.tabs.create()`
- **Copy Link**: Click icon button to copy URL to clipboard using Clipboard API
- **Bootstrap Icons**: Professional clipboard icon from Bootstrap Icons library
- **Theme Support**: Automatically follows system light/dark mode preference
- **Clean UI**: Responsive card-based layout with hover effects
- **Accessibility**: Proper aria-labels and semantic HTML structure

## Content Security Policy (CSP) Compliance

This extension strictly follows Chrome's CSP restrictions:
- ❌ NO inline scripts in HTML
- ✅ All scripts in external files
- ✅ All styles can be inline (CSS is allowed)
- ✅ No eval() or dynamic code execution
- ✅ No unsafe-inline attributes

**Key files for CSP compliance:**
- `popup.html` - No inline scripts (only CSS styling)
- `public/popup-init.js` - External script for initialization
- `src/popup.js` - Vue app entry point (external)
- All other scripts are external and bundled by Vite

## How It Works

### User Flow
1. User clicks extension icon in toolbar
2. Popup opens showing documentation links
3. User can either:
   - Click "Open Documentation" button to open link in new tab
   - Click clipboard icon to copy link URL to clipboard

## Key Components

### App.vue Structure
```typescript
interface DocumentationLink {
    id: string
    title: string
    url: string
}

// Two hardcoded links:
const links = ref<DocumentationLink[]>([
    { id: 'vue-docs', title: 'Vue 3 Documentation', url: 'https://vuejs.org' },
    { id: 'catalyst-docs', title: 'Catalyst Documentation', url: 'https://docs.catalyst.example.com' }
])

// Functions:
const openDocumentation(url) => chrome.tabs.create({ url })
const copyToClipboard(url) => navigator.clipboard.writeText(url)
```

### UI Layout
- Links container (flex column, scrollable)
- Link items (cards with hover effects)
- Link info (title + truncated URL)
- Link actions (Open Documentation + Copy buttons)

## Adding New Documentation Links

### Simple Addition
Edit [src/App.vue](./src/App.vue) - find the `links` array and add a new object:

```typescript
const links = ref<DocumentationLink[]>([
    // ... existing links ...
    {
        id: 'new-docs',
        title: 'New Documentation',
        url: 'https://example.com/docs'
    }
])
```

Then rebuild: `npm run build:extension`

## Using Bootstrap Icons

### Current Icon
- **Clipboard**: Used for copy button
- Import: `import ClipboardIcon from 'bootstrap-icons/icons/clipboard.svg?raw'`
- Implementation: `v-html="ClipboardIcon"` in SVG element

### Available Icons (2000+)
See [Bootstrap Icons Documentation](https://icons.getbootstrap.com/) for complete list.

Common alternatives:
- `clipboard2-check` - Clipboard with checkmark
- `link`, `external-link` - Link icons
- `copy` - Alternative copy icon
- `document` - Document icon
- `download` - Download icon
- `star` - Favorite/star
- `gear` - Settings

### Changing Icons
1. Replace import path with desired icon:
   ```typescript
   import NewIcon from 'bootstrap-icons/icons/new-icon-name.svg?raw'
   ```
2. Use in template: `v-html="NewIcon"`
3. Rebuild: `npm run build:extension`

## Debugging

### View Console Logs
1. **Popup**: Click extension icon → F12 → Console tab
2. **Background**: `chrome://extensions/` → Select extension → Check for errors
3. **Content Script**: Open webpage → F12 → Console tab

### Testing in Chrome
1. Build: `npm run build:extension`
2. Open `chrome://extensions/`
3. Enable Developer Mode (top right)
4. Click "Load unpacked"
5. Select `dist-extension/` folder
6. Click extension icon to test
7. F12 in popup to debug

## Do's and Don'ts

### ✅ Do
- ✅ Use Vue 3 Composition API with `<script setup>`
- ✅ Use TypeScript for type safety
- ✅ Use CSS variables from main.css for theming
- ✅ Use Bootstrap Icons for icons
- ✅ Keep components focused and reusable
- ✅ Test in both light and dark modes
- ✅ Run `npm run lint:fix` before committing
- ✅ Add proper aria-labels for accessibility

### ❌ Don't
- ❌ Change manifest version below 3
- ❌ Use inline scripts in popup.html
- ❌ Add external CDN resources (use npm packages)
- ❌ Use icons other than Bootstrap Icons
- ❌ Commit without running `npm run lint:fix`
- ❌ Add complex state management (keep it simple)
- ❌ Remove accessibility features
- ❌ **NEVER** create documentation .md files when editing code (unless explicitly requested by user)
  - Do NOT create SETUP_SUMMARY.md, BUILD_STATUS.md, COMPONENT_STRUCTURE.md, etc. on your own
  - Do NOT auto-generate documentation files as part of normal development
  - This clutters the repository and creates unnecessary noise
  - Only create documentation files if the user explicitly asks: "Create a guide for...", "Document this...", etc.
